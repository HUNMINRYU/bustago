## 5. 발표 Q&A 추가 질문 대응 (외워두기)

**Q. "AI 카운팅 정확도를 어떻게 검증했는가? 사람이 일일이 세어 비교했는가?"**

A: 데이터 기반 평가입니다. 실시간 수동 카운팅은 재현성이 떨어져서 5/14 회의 P0에서 지적되었고, 대안으로 ① CrowdHuman 공개 데이터셋에 라벨링된 bbox 1,857장으로 mAP를 측정하고, ② 시연 시 녹화한 영상에 사후 라벨(되감기·일시정지 가능)을 붙여 IN/BOARD 카운트와 모델 출력을 비교했습니다. 둘 다 결정론적이고 재현 가능합니다.

**Q. "데이터셋 라이선스와 개인정보는 어떻게 처리했는가?"**

A: 공개 baseline 데이터는 CC BY 4.0 (Keio DBA team CrowdHuman BlurHuman) — 얼굴이 이미 비식별 블러 처리된 버전입니다. 광주대 자체촬영분은 정류장 안내문과 동의 시간대 표시로 동의 절차를 진행하고, 거부 시 즉시 삭제·요청 시 삭제 절차를 `촬영_동의_및_삭제_절차.md`에 운영 책임자·시한과 함께 정의했습니다. 학습용 프레임도 `anonymize_faces.py`로 후처리합니다.

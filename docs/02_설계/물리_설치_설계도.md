# BUSTAGO 물리 설치 설계도

> **작성일:** 2026-05-01 | **최종 수정:** 2026-05-07
> **버전:** v2.0
> **변경 이력:** v1.0 천장 수직 촬영 → v2.0 기둥 측면 1.5~2m 높이, 45도 경사 촬영으로 변경 (2026-05-07 회의 — 인식률 우선 결정)

---

## 1. 설치 위치 개요

```
광주대학교 인성관 셔틀 정류장 (INS01)
├── 기존 버스 정류장 기둥 활용
├── 카메라 마운트: 기둥 상단 (지면 기준 약 2.5m 높이)
└── 장비 박스: 기둥 중간 (지면 기준 약 1.2m 높이)
```

---

## 2. 설치 구성도

> **v2.0 변경:** 천장 수직 촬영 → 기둥 측면 45도 경사 촬영으로 변경.
> 수직 촬영은 머리만 찍혀 얼굴/상체 특징 없어 YOLOv11 인식률 저하 우려.
> 경사 촬영은 상체가 포함돼 탐지 정확도가 높음.

### 카메라 시야각 (측면 45도 경사 촬영)

```
  기둥
  │
  │  [Pi Camera v2]  ←── 1.5~2.0m 높이, 45도 경사 하향
  │      ╲
  │       ╲  45°
  │        ╲
  │    ┌────╲─────────────────────────┐
  │    │  IN ╲라인 (정류장 진입 감지) │  ←── 정류장 진입로
  │    │      ╲                       │
  │    │       대기 공간               │
  │    │                              │
  │    │  BOARD 라인 (버스 탑승 감지) │  ←── 버스 탑승구
  │    └──────────────────────────────┘
  │           카메라 커버 범위 (약 3m×4m)
```

### 측면도 (기둥 단면, v2.0)

```
  2.0m  ┤    ┌──────────────────────────────────┐
        │    │  [Pi Camera v2]                  │
        │    │  기둥 측면 브라켓 마운트          │ ←── 지면 기준 1.5~2.0m
        │    │  45도 경사 하향 촬영              │      (인식률 우선)
        │    │  CSI 케이블 → 기둥 내부 관통      │
  1.5m  ┤    ├──────────────────────────────────┤
        │    │  방수함 (IP54, 300×200×100mm)    │
        │    │  내부: Jetson Orin Nano 8GB       │ ←── 지면 기준 1.2m
        │    │        WiFi 안테나               │
        │    │  전원: AC 어댑터 (12V/5A)        │
  0.0m  ┤    └──────────────────────────────────┘
               정류장 기둥

  [시연 대안] 실제 정류장 기둥 설치 어려울 경우:
  → 2~3m 삼각대 사용 (카메라 + Jetson 탑재)
  → 높이·각도 조정 용이, 이동 가능
```

### 설치 방식 비교

| 항목 | v1.0 (천장 수직) | v2.0 (기둥 측면 45도) |
|------|:---:|:---:|
| 촬영 대상 | 머리 윗면 | 상체 + 얼굴 |
| YOLOv11 인식률 | 낮음 (특징 부족) | **높음** (사람 특징 풍부) |
| 설치 높이 | 2.5m (천장) | **1.5~2.0m** (기둥 측면) |
| 설치 편의성 | 어려움 | **쉬움** |
| 시연 대안 | 없음 | **삼각대 2~3m** |

## 3. 장비별 설치 사양

### 3.1 Pi Camera v2

| 항목 | 사양 |
|------|------|
| 설치 높이 | 지면 기준 **1.5~2.0m** (기둥 측면) |
| 설치 각도 | **45도 경사 하향** (인식률 우선) |
| 시야각 | 62.2° × 48.8° (대각선 100°) |
| 커버 범위 | 약 3m × 4m (높이 1.8m, 45도 기준) |
| 연결 | CSI 케이블 (15핀→22핀 변환, 60cm) |
| 방수 | 방수 투명 돔 커버 (IP54) |
| 고정 | L형 브라켓 + M4 볼트 (기둥 측면) |
| **시연 대안** | **삼각대 2~3m** — 기둥 설치 어려울 경우 |

### 3.2 Jetson Orin Nano 8GB

| 항목 | 사양 |
|------|------|
| 설치 위치 | 기둥 중간 (1.2m) 방수 박스 내부 |
| 박스 규격 | 300 × 200 × 100mm 알루미늄 방수함 |
| 전원 | DC 9V–19V (AC 어댑터 → 방수함 내 전원 입력) |
| 통신 | WiFi (802.11ac, 내장 안테나) |
| 방열 | 방수함 외벽 히트싱크 접촉 방열 |
| 방수 등급 | IP54 (생활 방수) |

### 3.3 Raspberry Pi 4 (키오스크)

| 항목 | 사양 |
|------|------|
| 설치 위치 | 정류장 내부 안내판 후면 |
| 디스플레이 | 7인치 DSI 터치스크린 (안내판 전면 노출) |
| 전원 | USB-C 5V/3A |
| 통신 | WiFi (정류장 내 AP 경유 서버 접속) |
| 고정 | 디스플레이 후면 케이스 일체형 |

## 4. 라인 좌표 정의

카메라 영상 기준 IN/BOARD 라인 (1920×1080 해상도):

```
Y축
  │
  │   (0,0)──────────────── X축
  │
270 ┤  ─────── IN 라인 ─────────  (y=270, x: 200~1720)
  │          진입 감지 구간
  │
540 ┤  ──── BOARD 라인 ──────────  (y=540, x: 200~1720)
  │          탑승 감지 구간
  │
```

> **현장 튜닝 필요:** 실제 설치 후 `--in-line`, `--board-line` 파라미터로 조정.  
> 조정 명령: `python3 counter.py --in-line 270 --board-line 540 --debug`

## 5. 케이블·전원 배선

```
[정류장 전원 콘센트 220V AC]
        │
        ├── AC 어댑터 (12V/5A) ──→ Jetson Orin Nano 전원
        │
        └── USB 어댑터 (5V/3A) ──→ Raspberry Pi 4 전원

[Pi Camera v2]
        │
        └── CSI 케이블 (60cm) ──→ Jetson CSI 포트 (CAM0)

[WiFi 통신]
        Jetson ────── WiFi AP ──→ 서버 (POST /api/crowd-count)
        Pi 4   ────── WiFi AP ──→ 서버 (GET /api/predict)
```

## 7. 현장 체크리스트

```
설치 완료 확인 항목:

[ ] Jetson: `jtop`에서 GPU 사용률 확인 (counter.py 실행 중 > 20%)
[ ] Jetson: counter.py 25 FPS 이상 출력 확인
[ ] Jetson: POST /api/crowd-count 10초 간격 전송 확인 (서버 DB 증가)
[ ] Pi 4: Chromium 키오스크 모드 자동 실행 확인
[ ] Pi 4: 혼잡도 4단계 표시 60초 자동 갱신 확인
[ ] Admin: 실시간 카운팅 패널 녹색 dot (Jetson 연결됨) 확인
[ ] Watchdog: 프로세스 강제 종료 후 2~5분 내 자동 재시작 확인
[ ] 카메라: IN/BOARD 라인 통과 시 Track ID 단 1회 카운팅 확인
```

## 8. 리스크 및 대응

| 리스크 | 대응 방안 |
|--------|----------|
| 정류장 전원 콘센트 없음 | 이동식 배터리팩 (50,000mAh) + 인버터 사용, 시연 4시간 유지 가능 |
| 비/눈 날씨 | IP54 방수함으로 생활 방수 대응; 폭우 시 실내 시연으로 전환 |
| WiFi 신호 약함 | 핫스팟 라우터 현장 설치 (교내 WiFi 대비 안정적) |
| 카메라 시야각 부족 | 높이 조정 (2.5m→3.0m) 또는 광각 렌즈 추가 검토 |
| Jetson 과열 | 방수함 내 열전도 패드 + 외벽 히트싱크, 팬 추가 검토 |

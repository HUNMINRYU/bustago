## 1. Student PWA 화면

### 1.1 정류장 선택 화면

| 항목 | 내용 |
| --- | --- |
| 진입 트리거 | 학생 사용자가 PWA를 최초 실행하거나, 다른 화면에서 `정류장 다시 선택` 동작을 수행했을 때 진입한다. |
| UI 구성 요소 | `출발 정류장 드롭다운`: 정류장명 검색 및 선택<br>`목적지 드롭다운`: 목적지 정류장 선택<br>`조회 버튼`: 선택 완료 후 혼잡도 조회 요청<br>`최근 선택 영역`: 최근 조회한 조합 빠른 재선택<br>`입력 검증 메시지`: 미선택 상태 안내 |
| 사용자 행동 | 사용자는 출발 정류장과 목적지 정류장을 순서대로 선택한 뒤 `조회` 버튼을 누른다. 필요 시 최근 선택 조합을 탭하여 입력을 단축한다. |
| 시스템 응답 | 시스템은 선택값 유효성을 검증한 뒤 현재 혼잡도 화면으로 이동한다. 유효한 데이터가 있으면 최근 선택 목록을 갱신하고, 로딩 인디케이터를 표시한 후 혼잡도 데이터를 조회한다. |
| 오류 시 대응 | 정류장 데이터 로딩 실패 시 `정류장 목록을 불러오지 못했습니다` 메시지와 재시도 버튼을 노출한다. 출발지 또는 목적지 미선택 시 필드 하단에 검증 문구를 표시하고 조회를 차단한다. |

### 1.2 현재 혼잡도 화면

| 항목 | 내용 |
| --- | --- |
| 진입 트리거 | 정류장 선택 화면에서 조회가 완료되면 진입한다. 백그라운드 새로고침 또는 노선 카드 선택 후에도 동일 화면으로 갱신 진입할 수 있다. |
| UI 구성 요소 | `혼잡도 원형 인디케이터`: `여유`, `보통`, `혼잡`, `만차` 4단계 표시<br>`상태 텍스트`: 현재 혼잡도 등급 및 설명 문구<br>`탑승 추천 카드`: 추천 탑승 시점, 대체 노선 또는 대기 권장 메시지 제공<br>`새로고침 버튼`: 최신 데이터 재조회<br>`이전 화면 버튼`: 정류장 선택 화면 복귀 |
| 사용자 행동 | 사용자는 현재 혼잡도 단계와 추천 메시지를 확인하고, 필요하면 새로고침하거나 이전 화면으로 돌아가 다른 정류장을 재조회한다. |
| 시스템 응답 | 시스템은 최근 수집 데이터와 예측 결과를 결합해 인디케이터 색상과 등급 텍스트를 표시한다. 추천 카드에는 `지금 탑승 추천`, `5분 대기 권장`, `대체 노선 확인` 중 하나의 행동 메시지를 노출한다. |
| 오류 시 대응 | 실시간 데이터 조회 실패 시 마지막 성공 데이터 기준으로 화면을 유지하고 `최신 정보 갱신 실패` 배너를 표시한다. 데이터 자체가 없으면 예측 차트 또는 노선 카드로 이동을 제한하고 재시도 버튼을 제공한다. |

### 1.3 시간대별 예측 차트 화면

| 항목 | 내용 |
| --- | --- |
| 진입 트리거 | 현재 혼잡도 화면에서 `시간대별 예측 보기`를 선택하거나, 조회 결과 상세 영역을 확장했을 때 진입한다. |
| UI 구성 요소 | `6시간 바 차트`: 현재 시점 기준 향후 6시간 혼잡도 예측 표시<br>`시간 축`: 시간 단위 레이블 표시<br>`혼잡도 범례`: 여유/보통/혼잡/만차 색상 구분<br>`기준 시각 표시`: 예측 생성 시점 안내<br>`뒤로 가기 버튼`: 현재 혼잡도 화면 복귀 |
| 사용자 행동 | 사용자는 시간대별 바 높이와 범례를 비교해 덜 혼잡한 탑승 시점을 판단한다. 특정 시간 막대를 탭해 해당 시간의 예상 혼잡도 수치를 확인할 수 있다. |
| 시스템 응답 | 시스템은 예측 모델 결과를 6개 구간으로 시각화하고, 선택된 막대에 툴팁 형태로 예상 등급과 기준 설명을 제공한다. |
| 오류 시 대응 | 예측 데이터 생성 실패 시 차트 영역 대신 `예측 결과를 준비하지 못했습니다` 안내문과 재조회 버튼을 표시한다. 일부 시간 구간만 누락된 경우에는 `데이터 없음` 표식을 사용해 그래프 왜곡을 방지한다. |

### 1.4 노선별 혼잡도 카드 화면

| 항목 | 내용 |
| --- | --- |
| 진입 트리거 | 현재 혼잡도 화면에서 `노선 비교`를 선택하거나, 동일 목적지로 이동 가능한 대체 노선이 존재할 때 자동 노출된다. |
| UI 구성 요소 | `노선 카드 리스트`: 노선 번호, 도착 예정 시간, 현재 혼잡도, 예상 탑승 편의도 표시<br>`추천 배지`: 가장 여유 있는 노선 강조<br>`정렬 옵션`: 도착 순/혼잡도 순 전환<br>`노선 선택 버튼`: 선택 노선 상세 조회 |
| 사용자 행동 | 사용자는 리스트를 스크롤하며 노선별 상태를 비교하고, 추천 배지가 있는 노선을 우선 확인하거나 원하는 노선을 선택한다. |
| 시스템 응답 | 시스템은 목적지까지 이동 가능한 후보 노선을 혼잡도와 도착 예정 정보를 기준으로 정렬해 표시한다. 가장 여유 있는 노선에는 추천 배지를 부여하고 카드 강조 스타일을 적용한다. |
| 오류 시 대응 | 대체 가능한 노선이 없으면 `비교 가능한 노선이 없습니다` 빈 상태 화면을 보여준다. 노선 정보 일부가 누락되면 해당 카드에 `도착 정보 미확인` 표시를 추가하고 선택 기능은 유지한다. |

### 1.5 오프라인 Fallback 화면

| 항목 | 내용 |
| --- | --- |
| 진입 트리거 | PWA가 네트워크 단절 상태에서 실행되거나, API 요청 실패 후 Service Worker 캐시 데이터만 사용 가능한 경우 진입한다. |
| UI 구성 요소 | `오프라인 상태 배너`: 네트워크 미연결 안내<br>`마지막 업데이트 시간`: 캐시된 데이터 기준 시각 표시<br>`캐시 데이터 요약`: 최근 조회 정류장과 마지막 혼잡도 상태<br>`재연결 버튼`: 네트워크 복구 후 수동 재조회<br>`홈으로 이동 버튼`: 캐시 가능한 기본 화면 복귀 |
| 사용자 행동 | 사용자는 마지막 업데이트 시간을 확인한 뒤 캐시 데이터를 참고하거나, 네트워크가 복구되면 `재연결` 버튼을 눌러 최신 정보를 다시 요청한다. |
| 시스템 응답 | 시스템은 Service Worker 캐시에 저장된 마지막 성공 응답을 우선 표시하고, 네트워크 감지 이벤트 발생 시 자동으로 재연결 가능 상태를 활성화한다. |
| 오류 시 대응 | 캐시 데이터도 없으면 `저장된 데이터가 없습니다` 메시지와 함께 최소 안내 화면을 제공한다. 재연결 실패가 반복되면 버튼 하단에 실패 횟수와 네트워크 확인 문구를 표시한다. |

## 2. Admin Dashboard 화면

### 2.1 Summary Cards 섹션

| 항목 | 내용 |
| --- | --- |
| 진입 트리거 | 운영자가 Admin 대시보드에 로그인하여 메인 화면에 진입하면 가장 먼저 표시된다. |
| UI 구성 요소 | `평균 혼잡도 카드`: 백분율 값 표시<br>`만차 횟수 카드`: 일 기준 또는 선택 기간 기준 집계<br>`피크 시간대 카드`: 가장 혼잡한 시간대 표시<br>`모니터링 정류장 수 카드`: 현재 연결된 정류장 수 표시 |
| 사용자 행동 | 운영자는 카드 값을 빠르게 훑어 현재 운영 상태를 파악하고, 필요 시 상세 차트나 지도 섹션으로 시선을 이동한다. |
| 시스템 응답 | 시스템은 서버 집계 결과를 기반으로 핵심 지표를 카드 단위로 즉시 렌더링하고, 선택 기간이 바뀌면 각 카드 수치를 동기화 갱신한다. |
| 오류 시 대응 | 집계 API 실패 시 카드 내부에 `데이터 수집 실패` 상태를 표시하고 마지막 정상 업데이트 시각을 함께 보여준다. 일부 카드만 실패한 경우 정상 카드 값은 유지한다. |

### 2.2 실시간 카운팅 패널

| 항목 | 내용 |
| --- | --- |
| 진입 트리거 | 운영자가 대시보드 메인 또는 실시간 모니터링 탭을 열면 표시된다. |
| UI 구성 요소 | `현재 대기인원`: 정류장 대기 인원 실시간 수치<br>`IN 카운트`: 구역 진입 인원 카운트<br>`BOARD 카운트`: 탑승 완료 인원 카운트<br>`Jetson 연결 상태 표시`: `온라인` 또는 `오프라인` 배지<br>`마지막 수신 시각`: 마지막 이벤트 수신 시각 표시 |
| 사용자 행동 | 운영자는 인원 변화와 연결 상태를 관찰하고, 비정상 값이나 연결 단절이 보이면 즉시 하드웨어 상태를 확인한다. |
| 시스템 응답 | 시스템은 Jetson Orin Nano에서 송신한 카운팅 이벤트를 짧은 주기로 수신해 수치를 갱신한다. 연결 heartbeat가 유지되면 `온라인`, 일정 시간 미수신이면 `오프라인`으로 전환한다. |
| 오류 시 대응 | 연결이 끊기면 패널 전체를 회색 처리하고 `장치 응답 없음` 경고를 표시한다. 수치 갱신이 중단되면 마지막 정상값을 유지하되 실시간 표시는 비활성화한다. |

### 2.4 정류장 지도 섹션

| 항목 | 내용 |
| --- | --- |
| 진입 트리거 | 운영자가 대시보드 하단 지도 영역에 진입하거나 `지도 보기` 탭을 선택하면 표시된다. |

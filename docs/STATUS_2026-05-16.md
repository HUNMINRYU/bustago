## 3. baseline 평가 실측치 (대회 발표 reference)

```
모델:     yolo11n.pt (COCO 80-class 사전학습)
val set:  CrowdHuman BlurHuman v3 public val (1,857장, 54,626 person 인스턴스)
환경:     Intel i9-10900F CPU (Jetson 아님 — Jetson runtime은 별도 측정)

Precision  0.663
Recall     0.395
mAP50      0.458   ← 발표 핵심 수치
mAP50-95   0.258
추론 속도  57.9 ms/image (CPU)
```

**관찰**: Recall 0.395가 낮음. dense crowd / 가려진 인물을 많이 놓침. fine-tune의 핵심 개선 여지.
**예상**: 광주대 정류장은 CrowdHuman보다 단순(2~5명, 가려짐 적음)하므로 self_v1 val에서는 baseline이 이 수치보다 높게 나올 가능성. fine-tune의 효과는 self_v1 val 결과로 판단해야 함.

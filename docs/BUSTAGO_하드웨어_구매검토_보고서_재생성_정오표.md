## 사유 요약

- **Pi 4 CPU 한계 분석**: YOLOv8 실측 2~5 FPS → 실시간 트래킹(DeepSORT) 불가 → 중복 카운팅 발생 확인
- **Jetson Orin Nano Super**: 40 TOPS / 1024 CUDA cores → TensorRT 가속 시 25~40 FPS 확보
- **2보드 역할 분리**: Jetson(AI 전담) + Pi(Kiosk 전담)로 부하 최소화

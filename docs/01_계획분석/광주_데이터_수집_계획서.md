## 2. 수집 데이터 두 종류

본 계획은 *서울 공공데이터로 학습된 모델을 광주에 적용*하는 transfer를 정량 검증하기 위한 데이터 수집이다.

### 2.1 ML 혼잡도 모델용 — 광주대 승하차 데이터 (보류)

- **현황**: 광주 BIS API는 도착 정보·노선·정류소만 제공. **차내 혼잡도·승하차 이력은 미제공**.
- **결론**: 광주대 학사팀 또는 셔틀 운영사에서 별도 협조 필요. **본 계획 범위 밖**.
- **우회**: 시연·대회는 "서울 모델 + 광주 카운팅 데이터 결합"으로 진행하며, 본 한계는 `모델_신뢰성_한계_진술서.md`에 명시.

### 2.2 YOLO 카운팅 모델용 — 광주대 정류장 영상 ✅

본 계획서의 핵심.

| 항목 | 값 |
|---|---|
| 위치 | 광주대 인성관 정류장 (INS01) + 정문 정류장 (GATE01) |
| 기간 | 2026-05-21 (시연 당일 1차) + 2026-05-22~5/24 (보강 촬영) |
| 도구 | `hardware/record_demo.sh` — 자동 메타 + 백업 |
| 출력 | `datasets/bustago_person/self_v1/raw_videos/*.mp4` |

## 3. 수집 목표

### 3.1 매수 목표

| 우선순위 | 환경 조건 | 목표 영상 길이 | 통과 인스턴스 |
|---|---|---|---|
| 필수 | 시연 시간대(낮, 밝은 실내) | 60분 | 100건+ |
| 필수 | 출근·하교 피크 (8~9시 또는 17~18시) | 60분 | 150건+ |
| 권장 | 어두움 / 역광 (이른 아침 또는 저녁) | 30분 | 50건+ |
| 권장 | 비/우천 | 30분 (날씨 의존) | 50건+ |
| **총 목표** | — | **100~180분** | **300~600건** |

### 3.2 프레임 추출 후 데이터셋 매수

- `sample_frames.py --interval 2.0` (2초 간격) → 영상 1분당 30장
- 총 100분 영상 → 약 3,000장 frames
- auto-label + 검수 후 학습용으로 사용: 2,400장 (train) + 600장 (val) ≈ 8:2

→ 진단 § 권장 매수 500장 (val ≥ 100) 충족.

## 6. 학습 데이터 vs 평가 데이터 분리 기준

**가장 중요한 원칙**: 영상 단위 grouping. 한 영상의 모든 프레임은 train 또는 val 또는 eval 한 군데에만 들어간다 (data leak 방지).

| 데이터 셋 | 용도 | 입력 | 비중 |
|---|---|---|---|
| `self_v1/images/train` | YOLO fine-tune 학습 | 시연 영상 + 5/22 보강 영상 80% | 80% |
| `self_v1/images/val` | mAP 측정 (Detection 평가) | 동일 풀에서 별도 영상 20% | 20% |
| `eval_videos/*.mp4` | Counting IN/BOARD 오차율 측정 | 5/23 또는 5/30 별도 촬영 | 학습에 미포함 |

→ `eval_videos`는 학습 데이터에 포함되지 않은 영상이라 *진정한 generalization* 측정.

### R1: 동의 시간대 통과 인스턴스 < 100건

### R2: 광주 자체 데이터 수집 자체 실패 (촬영 장비 문제 등)
- 폴백: baseline yolo11n (mAP 0.458) 결과만 발표 + "광주 fine-tune은 후속 연구" 명시
- 영향: 외부 실사 v1.1 C-1 약점 그대로 노출 → 발표 점수 감소
- 회피: 시연(5/21) 영상 1세트는 무조건 확보 (counter.py가 안 돌아도 record_demo.sh는 별개 트랙)

### R3: 라벨 검수 인력 부족
- 폴백 1: 매수 축소 (3,000장 → 1,000장)
- 폴백 2: auto-label 결과 그대로 사용 (검수 스킵 — 진단 §8 R2 폴백 명시)

### R4: Phase 4 fine-tune mAP가 baseline 이하
- 폴백: baseline yolo11n.pt를 운영 모델로 결정 + 원인 분석 (진단 §8 R3)

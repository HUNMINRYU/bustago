## 렌더링 방법 (셋 중 편한 것 선택)

### A. 온라인 PlantUML (가장 빠름, 5초)
1. https://www.plantuml.com/plantuml/uml/ 접속
2. `.puml` 파일 내용 전체 복사 → 텍스트 영역에 붙여넣기
3. "Submit" 클릭 → PNG 즉시 표시
4. 우클릭 → "이미지 저장" → 판넬에 삽입

### B. VSCode 확장 (수정 편함)
1. VSCode에서 PlantUML 확장 설치 (`jebbs.plantuml`)
2. `.puml` 파일 열고 `Alt+D` → 실시간 프리뷰
3. 우클릭 → "Export Current Diagram" → PNG/SVG

### C. CLI (자동화)
```bash
# Java + Graphviz 설치 필요
sudo apt install -y default-jre graphviz
# plantuml.jar 다운로드 (한 번만)
wget https://github.com/plantuml/plantuml/releases/latest/download/plantuml.jar

# PNG 렌더
java -jar plantuml.jar -tpng 01_아키텍처_다이어그램.puml
# → 01_아키텍처_다이어그램.png 생성

# 고해상도 (판넬 인쇄용)
java -jar plantuml.jar -tpng -scale 3.0 01_아키텍처_다이어그램.puml
```

## 수정해야 할 부분 (필요 시)

### 박스형 (`01_아키텍처_다이어그램.puml`)
- 정보 너무 많아 보이면 → 각 rectangle 내부 `<size:11>...</size>` 줄 삭제
- 색상 변경 → 파일 상단 `!define` 항목 수정
  - 학교 컬러로 바꾸려면 광주대 공식 색 사용

### 컴팩트 (`01_아키텍처_데이어흐름_컴팩트.puml`)
- 이모지가 안 뜨거나 깨지면 → 텍스트로 교체 (예: `📷 Jetson` → `[Jetson]`)
- 인쇄용으로 흑백 변환 필요 시 → 모든 색상 #FFFFFF로 통일

# BUSTAGO 데모 실행 가이드

> **환경:** WSL2 (Windows Subsystem for Linux)  
> **소요 시간:** 약 1분  
> **목적:** 교수 회의·발표·시연 시 실제 화면을 보여주기 위한 로컬 실행법

---

## 1. 서버 시작 (터미널 1개로 전부)

프로젝트 루트에서 아래 명령어를 순서대로 실행한다.

```bash
# 1. 가상환경 활성화 + 패키지 설치 (최초 1회만)
cd /home/ahble/projects/Capstone/bustago
source .venv/bin/activate

# 2. Flask 백엔드 시작 (포트 5000)
PYTHONPATH=/home/ahble/projects/Capstone/bustago \
  python3 -m flask --app backend/app run --port 5000 &

# 3. 프론트엔드 정적 서버 시작 (포트 8080, API 프록시 포함)
python3 - << 'EOF' &
import http.server, urllib.request, socketserver

class ProxyHandler(http.server.SimpleHTTPRequestHandler):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, directory='frontend', **kwargs)
    def do_GET(self):
        if self.path.startswith('/api'):
            try:
                with urllib.request.urlopen('http://localhost:5000' + self.path) as r:
                    body = r.read()
                self.send_response(200)
                self.send_header('Content-Type', 'application/json')
                self.send_header('Access-Control-Allow-Origin', '*')
                self.end_headers()
                self.wfile.write(body)
            except Exception as e:
                self.send_error(502, str(e))
        else:
            super().do_GET()
    def log_message(self, *args): pass

with socketserver.TCPServer(('', 8080), ProxyHandler) as s:
    s.serve_forever()
EOF

# 4. 서버 준비 대기
sleep 2 && curl -s http://localhost:5000/api/health
```

출력에 `{"status":"ok",...}` 가 나오면 성공.

## 2. 브라우저에서 열기 (WSL2)

WSL2에서는 `xdg-open`이 없으므로 Windows 명령어를 쓴다.

```bash
# 방법 A — cmd.exe로 Windows 기본 브라우저 열기
cmd.exe /c start http://localhost:8080/student/index.html
cmd.exe /c start http://localhost:8080/admin/index.html

# 방법 B — PowerShell로 열기
powershell.exe Start-Process "http://localhost:8080/student/index.html"

# 방법 C — Windows 브라우저 주소창에 직접 입력 (가장 간단)
# WSL2의 localhost는 Windows에서 그대로 접속 가능
```

---

## 3. 접속 URL 정리

| 화면 | URL | 설명 |
|------|-----|------|
| **학생 PWA** | `http://localhost:8080/student/index.html` | 정류장 선택 → 혼잡도 확인 → 노선 추천 |
| **Admin 대시보드** | `http://localhost:8080/admin/index.html` | 실시간 카운팅 패널 + 차트 + 지도 |
| **API 상태** | `http://localhost:5000/api/health` | 서버 정상 여부 확인 |

## 4. 현재 동작 범위 (HW 없이 가능한 것)

| 기능 | 동작 여부 | 비고 |
|------|-----------|------|
| 혼잡도 예측 | ✅ 동작 | RandomForest 실제 추론 |
| 노선 추천 | ✅ 동작 | GATE01(419·518번), INS01(셔틀) |
| 정류장 드롭다운 | ✅ 동작 | INS01·GATE01 목록 표시 |
| 시간대별 예측 차트 | ✅ 동작 | 6시간 바 차트 |
| Admin 차트·지도 | ✅ 동작 | Chart.js + Leaflet 마커 |
| 실시간 카운팅 패널 | ⚠️ 오프라인 표시 | Jetson 미연결 (HW 없어서 정상) |
| AI 카운팅 수치 | ❌ 없음 | Jetson 부품 도착 후 실데이터 표시 |

## 5. 서버 종료

```bash
# Flask + 프론트엔드 서버 모두 종료
pkill -f "flask.*run"
pkill -f "socketserver.TCPServer"

# 또는 한 번에
kill $(lsof -ti:5000,8080) 2>/dev/null
```

---

## 6. 자주 발생하는 문제

| 증상 | 원인 | 해결 |
|------|------|------|
| `Address already in use` | 이전에 서버가 종료 안 됨 | `kill $(lsof -ti:5000,8080)` 후 재시작 |
| 화면은 뜨는데 데이터가 안 나옴 | Flask 서버 미시작 | `curl http://localhost:5000/api/health` 확인 |
| `ModuleNotFoundError: flask` | 가상환경 미활성화 | `source .venv/bin/activate` 후 재시작 |
| Windows 브라우저에서 접속 안 됨 | WSL2 포트 포워딩 이슈 | `netsh interface portproxy add v4tov4 listenport=8080 connectaddress=127.0.0.1 connectport=8080` (관리자 PowerShell) |

## 작품 내용요약 (양식의 가장 큰 칸 — A4 2/3 분량)

### 안 A — 표준안 (10줄, 6~7문장)

> BUSTAGO는 광주대학교 인성관·정문 정류장의 **버스 정류장 대기 혼잡도와 차내 만차 가능성을 예측하여 학생의 탑승 의사결정을 지원**하는 AI 기반 모바일·웹 시스템입니다.
> 서울시 공공데이터포털의 차내 혼잡도·승하차 이력·기상 데이터로 **LightGBM 혼잡도 예측 모델**(Accuracy 0.94)을 학습한 뒤, 광주 BIS API와 결합해 광주대학교 정류장에 직접 적용합니다.
> 정류장 현장에서는 **Jetson Orin Nano + YOLOv11 + DeepSORT** 기반 1대 카메라로 대기 인원을 25 FPS 실시간 카운팅하고, 라인 크로싱 알고리즘으로 IN·BOARD를 분리해 서버로 전송합니다.
> AI 카운팅 모델은 **CrowdHuman BlurHuman public 데이터셋(CC BY 4.0, 21,990장)에서 yolo11n baseline mAP50 0.458**(2026-05-16 실측)을 확보했고, 광주대학교 자체 데이터로 fine-tuning한 결과는 영상 사후 라벨 기반 결정론적 평가로 비교 검증합니다.
> 학생은 **모바일 PWA**로 출발지·목적지를 입력하면 노선별 4단계 혼잡도(여유·보통·혼잡·매우혼잡)와 광주 BIS 실시간 도착 정보, 대체 노선 추천을 받을 수 있고, 운영자는 **PC 웹 대시보드**로 정류장별 혼잡도·실시간 카운팅·증차 의사결정 통계를 모니터링합니다.
> 본 작품은 **공공데이터 학습 모델을 다른 지역으로 직접 이식(Transfer)** 한다는 점에서 기존 사례(부산대 캡스톤·뻐정 등)와 차별화되며, 광주대학교 현장 카운팅으로 모델 정확도를 운영적 KPI(IN 오차율 ≤15%, BOARD 오차율 ≤20%) 기준으로 재검증합니다.
> 시연 기준 SW 완성도 99% + AI 카운팅 baseline 검증 완료, 백엔드 9개 API + Flask + MySQL/SQLite 폴백 + PWA + Admin 대시보드 + AI 카운팅 모듈이 통합 동작하며, 2026년 6월 4일 경진대회 본행사에서 실물 Jetson·Pi 카메라 기반 라이브 데모를 진행할 예정입니다.

### 안 B — 압축안 (5줄, 3문장 — 칸이 좁을 때)

> BUSTAGO는 서울시 공공데이터로 학습한 LightGBM 혼잡도 예측 모델(Accuracy 0.94)을 광주대학교 정류장에 이식하고, Jetson Orin Nano + YOLOv11 + DeepSORT 기반 1대 카메라로 대기 인원을 25 FPS 실시간 카운팅하여 정류장 대기·차내 만차 가능성을 결합 예측하는 AI 시스템입니다.
> AI 카운팅은 CrowdHuman public 데이터셋(CC BY 4.0)에서 yolo11n baseline mAP50 0.458 확보, 광주대 자체 데이터 fine-tuning으로 개선 폭을 영상 사후 라벨 평가로 검증합니다.
> 학생은 모바일 PWA로 출발지·목적지를 입력해 노선별 4단계 혼잡도와 광주 BIS 실시간 도착정보·대체 노선 추천을 받고, 운영자는 PC 대시보드에서 정류장별 혼잡도·카운팅·통계를 모니터링하여 증차 의사결정을 지원받습니다.

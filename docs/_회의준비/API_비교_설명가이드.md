# 광주·서울 API 혼잡도 비교 — 구두 설명 가이드

> **담당 문서:** `docs/06_조사데이터/광주_서울_API_혼잡도_비교.md`  
> **설명 예상 시간:** 2~3분  
> **핵심 메시지:** "광주 API에 혼잡도 필드가 없다는 건 추정이 아니라 API 명세 문서에서 직접 확인한 사실입니다."

---

## 1. 30초 요약 (교수가 "간단히 설명해봐"라고 물으면)

> "광주 버스 API에는 혼잡도 데이터가 아예 없습니다.  
> 이건 추정이 아니라 광주 BIS API 명세서를 직접 확인한 결과입니다.  
> 그래서 서울시 데이터로 학습한 RandomForest 모델을 광주에 그대로 씁니다.  
> 서울과 광주 모두 국토교통부 표준 4단계(여유·보통·혼잡·매우혼잡)를 따르기 때문에 적용이 타당합니다."

---

## 2. 설명 흐름 (단계별 말할 순서)

### Step 1 — 왜 이걸 조사했나

말할 내용:
> "4월 30일 교수님 지적이 '광주 API에 혼잡도가 없다는 게 추정인가, 사실 확인인가?' 였습니다.  
> 그래서 광주 BIS API 공식 명세 문서를 직접 열어서 확인했습니다."

### Step 2 — 서울 API는 어떤가

말할 내용:
> "서울 열린데이터광장의 getBusPosByRtidService API에는  
> `congestCd`라는 필드가 있고, 0=여유, 1=보통, 2=혼잡, 3=매우혼잡으로 실시간 제공됩니다.  
> 이 데이터로 RandomForest 모델을 학습시켰습니다."

### Step 3 — 광주 API는 어떤가

말할 내용:
> "광주 BIS API 명세를 확인한 결과, 제공하는 필드는 버스 위치(위도·경도), 도착 예정 시간, 노선 정보입니다.  
> 혼잡도 필드(`congestCd`나 그에 해당하는 것), 탑승 인원 수, 만차 여부 — 전부 없습니다.  
> 그래서 광주 데이터만으로는 모델을 학습시킬 수가 없었습니다."

### Step 4 — 그럼 왜 서울 모델을 광주에 그대로 쓸 수 있나

말할 내용:
> "두 가지 근거가 있습니다.  
> 첫째, 혼잡도 4단계 분류(여유·보통·혼잡·매우혼잡)는 국토교통부 표준입니다. 서울이든 광주든 같은 기준을 씁니다.  
> 둘째, 저희 모델의 입력 feature 7개(시간대, 요일, 날씨, 기온, 경유 노선 수 등)는 지역과 관계없는 보편적인 변수입니다.  
> 따라서 서울에서 학습한 패턴이 광주에도 적용 가능합니다."

---

## 3. 핵심 숫자 (반드시 암기)

| 사실 | 내용 |
|------|------|
| **광주 BIS API 혼잡도 필드** | **없음** (API 명세 기반 확인) |
| **서울 API 혼잡도 코드** | congestCd: 0=여유, 1=보통, 2=혼잡, 3=매우혼잡 |
| **모델 feature 수** | 7개 (시간대·요일·날씨·기온·직전 승차·하차·노선 수) |
| **모델 교차검증 정확도** | CV 0.9962 (5-fold) |
| **분류 기준** | 국토교통부 표준 4단계 — 서울·광주 동일 |

## 4. 예상 질문 & 답변

**Q: API 명세를 "직접" 확인했다는 게 어디서 확인한 건가요?**  
A: "광주 대중교통 정보시스템(광주 BIS) 공식 API 문서를 참조했습니다. 제공 필드 목록에 혼잡도 관련 항목이 없습니다. 이 내용은 `docs/06_조사데이터/광주_서울_API_혼잡도_비교.md`에 확인 일자와 확인자 이름으로 기록되어 있습니다."

**Q: 서울 모델을 광주에 쓰면 정확도가 떨어지지 않나요?**  
A: "가능성은 있습니다. 그래서 Jetson 카메라로 수집한 광주 실측 데이터를 `crowd_counts` DB에 계속 쌓고 있습니다. 데이터가 충분히 쌓이면 광주 특화 모델로 재학습하는 기반을 마련해 두었습니다. 현재는 서울 모델이 충분히 합리적인 시작점입니다."

**Q: 왜 처음부터 광주 데이터를 수집해서 학습하지 않았나요?**  
A: "광주 BIS API 자체에 혼잡도 레이블이 없어서 지도학습용 정답 데이터를 만들 수가 없었습니다. 서울 API는 실시간 congestCd를 제공하기 때문에 대규모 레이블 데이터 확보가 가능했습니다."

**Q: 분류가 4단계인 이유가 뭔가요?**  
A: "국토교통부가 대중교통 혼잡도 표준으로 정한 4단계입니다. 저희가 임의로 만든 기준이 아닙니다. 뻐정 프로젝트는 3단계를 썼는데, 저희는 표준에 맞게 4단계를 적용했습니다."

## 🎯 오늘 (D-12, 5/23 금) — 끝내야 할 것 4가지

### ① 지도교수 연락 (코드 아님 — 가장 시급)
- 지도교수에게 5/25(일) 또는 5/26(월) 오전 서명 가능 일정 문의
- 사유: 캡스톤 경진대회 판넬 제출 (5/26 마감)
- 만나기 어려우면 → 출력본 학교 우편함·연구실 문 앞 두고 사진 회신

### ② 안내문 A4 출력 (5/24 촬영 전 필수)
가이드: `docs/01_계획분석/광주_데이터_수집_계획서.md` §C.2 템플릿

채워야 할 부분:
- `010-XXXX-XXXX` → 류훈민 실제 휴대폰
- `지도교수 ___` → 지도교수명

출력 후 정류장 부착할 테이프도 챙기기.

### ③ 외장 SSD 마운트 확인 (Jetson에서)
```bash
ssh ahble@172.30.1.75
df -h                            # 외장 SSD 보이는지
ls /media/*/ 2>/dev/null         # 마운트 경로 확인
# 안 보이면:
sudo mkdir -p /media/jetson/BUSTAGO_SSD
sudo mount /dev/sda1 /media/jetson/BUSTAGO_SSD
```

### ④ record_demo.sh dry-run (5분)
```bash
cd ~/bustago/hardware
bash record_demo.sh --duration 60 --station INS01 --output /tmp/dryrun.mp4
ls -lh /tmp/dryrun.mp4           # 파일 생성됨? 정상 사이즈?
mpv /tmp/dryrun.mp4 || vlc /tmp/dryrun.mp4   # 재생 확인
```

→ 정상 동작 확인되면 내일 진짜 촬영 OK.

## 5. 외함 설치 방식 권장안

v1의 최대 오류인 외함 규격 문제에 대해 두 가지 방식을 제안한다.

### 방식 A: 디스플레이 외부 마운트 (권장)

```
┌─────────────────────┐
│  7인치 터치스크린     │ ← 외부 노출 (VESA 또는 브라켓 고정)
│  (194×110mm)        │
└────────┬────────────┘
         │ DSI 리본
    ┌────┴─────────┐
    │  하이박스      │ ← 250×200×120mm, IP65
    │  [Pi 4 + PSU] │    케이블 글랜드로 DSI·전원 인입
    │  [쿨링팬]     │
    └──────────────┘
```

- **장점:** 디스플레이 시인성 확보, 터치 조작 가능, 소형 박스로 비용 절감
- **단점:** 디스플레이 별도 방수 처리(아크릴 커버) 필요
- **적합:** 지붕이 있는 정류장 (인성관 셔틀)

### 방식 B: 전체 내장형

```
┌─────────────────────────┐
│  하이박스 300×250×150mm   │
│  ┌──────────────────┐   │
│  │ 7인치 디스플레이    │   │ ← 투명 아크릴 윈도우
│  └──────────────────┘   │
│  [Pi 4] [PSU] [팬]      │
└─────────────────────────┘
```

- **장점:** 완전 밀폐, 방수·방진 최적
- **단점:** 큰 박스 필요, 투명 윈도우 가공 필요, 터치 불가능
- **적합:** 완전 야외 (정문 정류장)

## 7. Docker 환경 연동 수정사항

현재 프로젝트는 `docker-compose.yml`로 배포되며, nginx가 프론트엔드(`:80`)와 백엔드(`:5000`)를 프록시한다.

### Kiosk URL 수정 (설계서 대비)

```diff
# 기존 (설계서 v1.0)
- --app=http://BACKEND_IP:5000/student/index.html

# 수정 (Docker 환경)
+ --app=http://SERVER_IP/student/index.html
```

### systemd 서비스 파일 수정

```bash
ExecStart=/usr/bin/chromium-browser \
  --kiosk \
  --noerrdialogs \
  --disable-infobars \
  --disable-session-crashed-bubble \
  --app=http://SERVER_IP/student/index.html
```

> `SERVER_IP`는 Docker Compose가 실행되는 서버의 IP. nginx가 `:80`에서 수신하므로 포트 생략 가능.

## 1. v2 → v3 전환 근거

### 1.1 왜 Pi 4 Only가 부족한가

| 비교 항목 | v2 (Pi 4 × 2세트, 3카메라) | v3 (Jetson + Pi 4 × 1세트, 1카메라) |
|-----------|---------------------------|-------------------------------------|
| AI 추론 성능 | CPU 2~5 FPS | **GPU 25~40 FPS** |
| DeepSORT 트래킹 | 사실상 불가 (CPU) | **실시간 가능 (1024 CUDA)** |
| 카메라 대수 | 3대 (저 FPS 보상) | **1대 (고 FPS로 충분)** |
| 중복 카운팅 방지 | 불가 → 부정확 | **Track ID 기반 정확** |
| 카운팅 품질 | 시연 수준 | **실측(Ground Truth) 수준** |
| 키오스크 안정성 | AI 부하와 경합 | **독립 보드, 안정적** |
| 정류장 수 | 2곳 (분산) | 1곳 (집중) |
| 총 예산 | 750,400원 | **~800,000원** |

### 1.2 핵심 판단

> **같은 예산(80만원)으로 "2곳 부정확"보다 "1곳 정확"이 시연·경진대회에서 훨씬 효과적이다.**
>
> - Pi 4 CPU에서 2~5 FPS: 사람이 5~10 프레임 사이에 크게 이동 → IoU 매칭 실패 → DeepSORT 추적 불가
> - Jetson GPU에서 25~40 FPS: 프레임 간 이동이 몇 픽셀 → 칼만 필터 + IoU 매칭 정확 → 안정적 Track ID 유지
> - 카메라 3대로 저 FPS를 보상하는 것은 구조적으로 불가능 (각 카메라별로 독립 DeepSORT 필요, CPU 부하 3배)

## 6. 외함 설치 방식

### 6.1 권장안: 디스플레이 외부 마운트 (방식 A)

```
          [Pi Camera v2]  ← 높이 2.5~3m, 하향 45°
               │ CSI 연장 케이블
               │
┌──────────────┴────────────────┐
│  7인치 터치스크린               │ ← 외부 노출 (브라켓 고정)
│  (800×480, 194×110mm)         │    아크릴 커버 방수 처리
└────────┬──────────────────────┘
         │ DSI 리본
    ┌────┴──────────────────┐
    │  하이박스 250×200×120mm │ ← IP65
    │                       │
    │  [Jetson Orin Nano]   │    Dev Kit 내장팬으로 냉각
    │  [Pi 4 + 방열판]      │    ABS 케이스 내 장착
    │  [전원 어댑터 ×2]      │
    │                       │
    └───────────────────────┘
         ↑ 케이블 글랜드 ×3
       (전원, CSI, 통풍)
```

- **적합 환경:** 지붕이 있는 인성관 셔틀 정류장
- **장점:** 디스플레이 시인성 확보, 터치 조작 가능
- **주의:** Jetson Dev Kit 크기 (100×79mm)를 감안하여 하이박스 내부 배치 확인 필요

### 6.2 하이박스 내부 배치 검증

| 장비 | 크기 (mm) | 위치 |
|------|----------|------|
| Jetson Orin Nano Dev Kit | 100 × 79 | 좌측 |
| Raspberry Pi 4 (케이스 포함) | 95 × 65 | 우측 |
| 전원 어댑터 ×2 | 별도 외부 또는 하단 | 하단 |

## 9. v1 → v2 → v3 변경 이력

| 버전 | 날짜 | 구조 | 정류장 | 핵심 변경 | 예산 |
|------|------|------|--------|----------|------|
| v1 | 2026-04-05 | Pi 4 Only | 2곳 | 초안 작성 | 345,070원/세트 |
| v2 | 2026-04-09 | Pi 4 Only | 2곳 | 방수박스 규격 수정, 방열판 추가 | 360,200원/세트 |
| **v3** | **2026-04-10** | **Jetson + Pi 4** | **1곳** | **GPU 기반 AI 전환, 카메라 1대 고FPS** | **769,000원/세트** |

### v3 주요 변경 근거

1. **Pi 4 CPU 한계 확인:** YOLOv8-nano 2~5 FPS에서 DeepSORT 트래킹 사실상 불가
2. **카메라 대수 ≠ 정확도:** 3대 × 저 FPS보다 1대 × 고 FPS가 트래킹 정확도에서 압도적
3. **예산 효율:** 동일 80만원으로 "2곳 부정확"보다 "1곳 정확"이 시연·경진대회 성과에 유리
4. **역할 분리:** AI 추론(Jetson)과 디스플레이(Pi 4) 분리로 양쪽 안정성 확보

## 5. 위험 + 폴백

### R1. develop이 원격에서 다른 사람이 push한 상태

- 감지: `git pull origin develop`에서 conflict 또는 추가 커밋
- 폴백: pull 결과 검토. 충돌 시 해결 후 머지 진행. 무관한 작업이면 그대로 머지

### R2. 머지 도중 충돌

- 감지: `git merge`가 CONFLICT 출력
- 폴백: 충돌 파일 확인 → 양쪽 의도 살려 수동 해결 → `git add` + `git commit`
- 비상: `git merge --abort`로 머지 취소 후 분석

### R3. feat/hunmin 삭제 실수

- 감지: 삭제 후 push까지 했는데 일부 작업 누락 발견
- 폴백: `backup/before-rebase-2026-05-13` 브랜치는 보존되어 있음. 또한 `git reflog`로 90일 내 복원 가능
  ```bash
  git reflog | grep feat/hunmin
  git branch feat/hunmin <SHA>
  ```

### R4. 원격 삭제 거부 (default branch 보호 등)

- 감지: `git push origin --delete feat/hunmin`이 protected branch 오류
- 폴백: GitHub 웹 → Settings → Branches에서 보호 규칙 해제 또는 GitHub UI에서 직접 삭제

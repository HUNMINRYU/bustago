## 1. 핵심 진술 (발표 슬라이드 한 줄용)

> **"본 시스템의 RandomForest Accuracy 0.9993은 합성/quantile 라벨링 결과로,
> 광주대 실측 데이터로 검증되기 전까지는 *모델 구조 검증치*로만 해석해야 한다."**

## 2. 수치별 한계

### 2.1 ML 혼잡도 모델 (RandomForest, 운영 중)

| 메트릭 | 값 (2026-05-16 재학습) | 한계 |
|---|---|---|
| Accuracy | **0.9993** | 합성 라벨링 (서울 공공데이터 14,616건 + 분위수 기준 4단계) → 진정한 generalization 측정 X |
| F1 macro | **0.9993** | 동일 |
| CV 5-fold | **0.9991 ± 0.0007** | 시계열이 아닌 random split — 시간 의존성 무시 |

**왜 0.9993이 비현실적인가**:
1. **Quantile 라벨링**: `boarding`을 분위수로 자른 라벨이라 모델이 사실상 `boarding` 자체를 학습. Feature importance에서 hour 0.49, temperature 0.26, route_count 0.13으로 분산되어 있지만, `boarding`이 일정 부분 hour와 강한 상관이 있어 *간접 누수* 가능성.
2. **Random split**: 시간 흐름에 따른 데이터 분포 shift를 측정하지 못함. 실 운영은 *미래 시점 예측*이라 결과 더 낮을 가능성.
3. **광주 실측 0건**: 학습·평가 데이터 모두 서울 — 도메인 이동 후 정확도는 측정되지 않음.

**실 광주 데이터 적용 시 현실적 기대치**:

| 시나리오 | 예상 Accuracy | 근거 |
|---|---|---|
| 서울 분포와 비슷한 광주대 시간대 (8~9시 출근) | 0.75 ~ 0.85 | Transfer Learning 일반적 하락폭 |
| 셔틀 등 광주대 고유 패턴 | 0.55 ~ 0.70 | 학습 데이터에 셔틀 정류장 정보 없음 |
| **평균 기대치** | **0.70 ~ 0.80** | 발표 시 "0.9993보다 낮을 것으로 정직하게 예측" |

### 2.2 YOLO 카운팅 모델 (yolo11n baseline, 2026-05-16 측정)

| 메트릭 | 값 | 한계 |
|---|---|---|
| Precision | 0.663 | CrowdHuman 군중 환경 |
| Recall | 0.395 | dense crowd / 가려짐 많이 놓침 |
| **mAP50** | **0.458** | val 1,857장 / 인스턴스 54,626건 |
| mAP50-95 | 0.258 | bbox 위치 정밀도 낮음 |

**광주대 정류장 적용 시 기대치**:
- CrowdHuman은 평균 29.4 person/image의 군중 밀집, 광주대 정류장은 평균 2~5명 → **더 단순한 환경**.
- 일반적으로 baseline mAP가 0.10~0.15 향상될 가능성 (도메인 단순화 효과).
- 자체 fine-tune 후 추가 0.05~0.10 향상 기대.
- **현실적 목표**: mAP50 0.60~0.70 (광주대 자체 val 기준).

### 2.3 Counting 정확도 (IN/BOARD 오차율)

| 항목 | 측정값 | 한계 |
|---|---|---|
| baseline IN 오차율 | **미측정** | 영상 사후 라벨 데이터 0건 |
| fine-tune IN 오차율 | **미측정** | Phase 6 (6/2~6/3) 대상 |
| 시연 계획서 목표 | ±2명 이내 | 측정 전 약속 — 검증 후 갱신 필요 |

→ **시연 당일(5/21) 실측 + 시연 후 영상 사후 라벨링(6/2)을 통해 최초 측정값 확보 예정**.

## 3. 발표 자료에 반영할 표현 (권장 문구)

### 슬라이드 본문 (1~2줄)

> "RandomForest 정확도 0.9993은 서울 공공데이터 14,616건 + 분위수 라벨링 기반의
> *모델 구조 검증치*이며, 광주대 실측 검증 시 0.7~0.8 수준이 현실적입니다."

### Q&A 모범답안

**Q. "Accuracy 0.9993은 비현실적이지 않습니까?"**

A: 솔직히 비현실적입니다. 합성/quantile 라벨링 결과이고, 광주 실측 데이터로는
0.7~0.8 수준이 현실적 기대치입니다. 본 수치는 *모델 구조와 파이프라인이
end-to-end 동작함을 검증*하는 reference로만 해석해 주시기 바랍니다. 광주대 자체
데이터 수집은 5/22~5/29 일정으로 별도 트랙에서 진행 중이며, 결과는 6/4 대회에서
fine-tune 비교표로 보고드립니다.

**Q. "그럼 지금 보여주는 화면의 혼잡도 4단계 표시도 의미 있습니까?"**

A: 시연 화면의 4단계 표시는 *시스템 통합 데모* 목적입니다. 모델 구조와 PWA·DB
연동·실시간 카운팅 파이프라인이 동작함을 보이는 것이고, 학생에게 실제 정확한
혼잡도를 제공하는 운영 단계는 광주 데이터 학습 후입니다. 이 한계는 본 진술서에
명시되어 있습니다.

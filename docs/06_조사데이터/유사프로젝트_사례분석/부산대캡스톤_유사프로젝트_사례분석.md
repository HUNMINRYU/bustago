### 프로젝트 2: 버스 내부 승하차 인원 측정 및 사고 감지 시스템

**기본 정보**

| 항목 | 내용 |
|------|------|
| 프로젝트명 | Jetson TX2에서 YOLOv5와 DeepSORT를 활용하여 버스 내부 승차 또는 하차 인원 측정 및 사고를 감지하는 시스템 |
| 개발 기관/주체 | 부산대학교 정보컴퓨터공학부 2023년 캡스톤디자인 |
| 개발 연도 | 2023년 |
| 출처 | GitHub: https://github.com/pnucse-capstone/capstone-2023-1-26 |

**핵심 기술 스택**

- 언어/프레임워크: Python, MQTT 프로토콜(데이터 전송), HLS 프로토콜(영상 스트리밍)
- AI/ML: YOLOv5 + DeepSORT
- 하드웨어: Jetson TX2 (각 버스에 개별 설치), 버스 내부 CCTV 3대(입·출구, 내부)
- 데이터베이스: (클라우드 서비스 연동 언급은 있으나 정확한 명시 없음. 확인 필요)

**혼잡도 예측 방식**

이 프로젝트는 버스 한 대에 카메라 3대를 설치하여 실시간으로 측정하는 방식이다. 입구 카메라로 타는 사람 수를 체크하고, 출구 카메라로 내리는 사람 수를 체크. 마지막 내부 카메라로 승객이 넘어지는 사고를 감지한다.

사람을 세는 방식은 YOLOv5로 영상에서 사람을 찾아내, DeepSORT를 통해 사람에게 고유 번호를 붙여 추적하는 방식을 사용한다. 세어진 승·하차 인원수는 MQTT라는 경량 통신 방식을 통해 서버로 전송, 서버에서는 버스 번호별로 데이터를 구분하여 관리하며 관리자는 특정 버스의 정보를 구독하여 실시간으로 확인할 수 있다.

사고 감지의 경우, 넘어짐이 감지되면 5초 간격의 영상 조각을 생성하여 총 30초 분량의 사고 영상을 자동으로 만들어 전송하게 된다. 이를 통해 관리자가 사고 상황을 실시간으로 확인할 수 있다.

**카메라/하드웨어 구성**

버스 한 대당 Jetson TX2 보드 1개, CCTV 3대(입·출구, 내부)로 구성된다. Jetson TX2에서 RTSP 프로토콜로 CCTV 3대의 카메라 영상을 동시에 수신하여, 보드 내에서 직접 AI 처리(사람 탐지 및 추적, 사고 감지)한다.

이 프로젝트의 핵심이 되는 설계는 엣지 처리로, 각 버스에 설치된 Jetson TX2가 현장에서 바로 AI 연산을 수행하고, 결과 데이터(인원수, 사고 발생 여부)만 전송하여 여러 대의 버스에 동시 적용이 가능하도록 설계되었다.

**우리 프로젝트 반영 가능 사항**

- **DeepSORT 적용 사례:** BUSTAGO와 마찬가지로 YOLOv5 + DeepSORT 조합으로 사람을 추적하고 세는 방식을 사용했다. BUSTAGO는 YOLOv8-nano + DeepSORT를 사용하는데, 이 프로젝트가 같은 추적 기술로 버스 환경에서 정상 작동함을 보여주므로 우리 프로젝트의 기술 선택이 타당하다는 검증이 된다.
- **MQTT 통신 방식:** 이 프로젝트는 MQTT라는 가벼운 통신 프로토콜로 인원수 데이터를 전송하는 형식인데, BUSTAGO는 현재 Flask 서버로 데이터를 전송하는 구조로. 향후 여러 정류장으로 확장할 경우 MQTT 같은 경량 통신 방식을 검토해볼 수 있다.

**차별점 (BUSTAGO vs 이 프로젝트)**

- **측정 위치:** 부산대 캡스톤 프로젝트는 버스 "내부"에 카메라를 설치하여 승·하차 인원을 센다. BUSTAGO의 경우, 버스 "정류장"에 카메라를 설치하여 대기 인원을 셈 하는 형식이다. "버스 안에 지금 몇 명인가?"와 "정류장에서 얼마나 기다리고 있는가"의 차이를 보여준다.
- **예측과 측정:** 부산대 캡스톤 프로젝트는 실시간으로 현재 상태만 측정한다. BUSTAGO는 실시간 측정에 더해 ML 모델을 통한 미래 혼잡도 예측까지 제공한다.
- **하드웨어 보드:** 부산대 캡스톤 프로젝트는 Jetson TX2(2017년 출시)를 사용하지만 BUSTAGO는 Jetson Orin Nano(2023년 출시)를 사용하여 약 4배 차이의 GPU 성능을 확보하였다.
- **카메라의 수:** 부산대 캡스톤 프로젝트는 버스 한 대당 3대의 카메라가 필요한데(입·출구, 내부), BUSTAGO는 정류장당 1대의 카메라로 운영되어 설치·유지 비용이 적다는 차이점이 있다.
- **데이터 활용 범위:** 부산대 캡스톤 프로젝트는 카메라로 세어진 실시간 인원수만 전송하는것에 비해, BUSTAGO는 날씨, 요일, 시간대 등 외부 데이터를 결합하여 예측 모델을 구동한다.

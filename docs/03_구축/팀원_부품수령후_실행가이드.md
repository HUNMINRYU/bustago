## STEP 5 — Jetson: YOLOv11 TensorRT 변환 (류훈민, Day 2)

> YOLOv11 모델명은 `yolo11n` (yolov11 아님 — ultralytics 명명 규칙)

```bash
source ~/bustago-env/bin/activate

python3 -c "
from ultralytics import YOLO
model = YOLO('yolo11n.pt')       # 자동 다운로드 (~6MB)
model.export(format='engine', half=True, imgsz=640)
print('TensorRT 변환 완료: yolo11n.engine')
"

ls -lh yolo11n.engine            # 5~15MB면 성공

# 추론 테스트
python3 -c "
from ultralytics import YOLO
import numpy as np
model = YOLO('yolo11n.engine')
dummy = np.zeros((640,640,3), dtype='uint8')
result = model(dummy)
print('TensorRT 추론 OK')
"
```


```
  - 호스트명: bustago-kiosk
  - SSH 활성화
  - 사용자명: pi / 비밀번호: 팀장에게 문의
  - WiFi: 현장 WiFi SSID/비밀번호
```

### 7-2. 패키지 설치

```bash
ssh pi@bustago-kiosk.local

sudo apt update && sudo apt upgrade -y
sudo apt install -y chromium-browser unclutter xdotool python3-pip fonts-noto-cjk

# 자동 로그인 설정
sudo raspi-config
# → System Options → Boot/Auto Login → Console Autologin
```

### 7-3. Kiosk 서비스 등록

```bash
sudo nano /etc/systemd/system/bustago-kiosk.service
```

```ini
[Unit]
Description=BUSTAGO Kiosk Browser
After=network.target graphical.target

[Service]
Type=simple
User=pi
Environment=DISPLAY=:0
Environment=XAUTHORITY=/home/pi/.Xauthority
ExecStartPre=/bin/sleep 5
ExecStart=/usr/bin/chromium-browser \
  --kiosk \
  --noerrdialogs \
  --disable-infobars \
  --no-first-run \
  --disable-restore-session-state \
  http://SERVER_IP/student/index.html
Restart=always
RestartSec=5

[Install]
WantedBy=graphical.target
```

```bash
# SERVER_IP를 실제 서버 IP로 변경 후:
sudo systemctl daemon-reload
sudo systemctl enable bustago-kiosk.service
sudo systemctl start bustago-kiosk.service
sudo systemctl status bustago-kiosk.service   # active (running) 확인
```

## STEP 8 — 카메라 현장 설치 (팀 전체, Day 3~4)

> **v2.0 설치 방식:** 기둥 측면 1.5~2.0m 높이, 45도 경사 하향

### 8-1. 현장 설치 (정류장 기둥 활용)

```
1. 기둥 측면 1.5~2.0m 지점에 L형 브라켓 위치 선정 (박건우)
2. L형 브라켓 M4 볼트로 기둥에 고정 (박건우+이건영, 30분)
3. 방수함(IP54) 브라켓 아래 1.2m 지점에 고정 (박건우+이건영, 30분)
4. Jetson 방수함 내 설치 + 전원 연결 (류훈민, 20분)
5. Pi Camera 브라켓에 45도 각도로 마운트 + CSI 케이블 연결 (류훈민, 20분)
6. WiFi 연결 확인 (이트겔, 20분)
```

### 8-2. 시연 대안 — 삼각대 사용

```
기둥 설치 어려울 경우:
→ 2~3m 삼각대에 Pi Camera + Jetson 탑재
→ 삼각대 헤드를 45도로 기울여 정류장 방향 촬영
→ 높이·각도 현장에서 자유롭게 조정 가능
```

### 8-3. 라인 튜닝 (류훈민, 현장에서)

```bash
# 디버그 모드로 실제 사람 통과 위치 확인

# 라인 위치 조정 (0=상단, 1=하단)
```

## STEP 9 — E2E 통합 테스트 (이트겔 주도, Day 3)

### 9-1. 서버 실행 확인

```bash
# 서버에서 (Docker 또는 직접 실행)
cd ~/bustago && docker-compose up -d
# 또는
cd ~/bustago/backend && python3 app.py

curl http://SERVER_IP/api/health   # → {"status":"ok"}
```

### 9-2. Jetson 서버 연동 실행

```bash
# SERVER_IP를 실제 서버 IP로 교체
python3 counter.py \
  --camera 0 \
  --model ~/yolo11n.engine \
  --server http://SERVER_IP/api/crowd-count \
  --station-id INS01 \
  --post-interval 10
```

**성공 기준:** 10초마다 `POST 200 OK` 출력

### 9-3. E2E 흐름 확인

```bash
# 서버에서 DB 증가 실시간 모니터링
watch -n 5 'sqlite3 backend/bustago.db \
  "SELECT * FROM crowd_counts ORDER BY created_at DESC LIMIT 3;"'
```

| 확인 항목 | 방법 |
|-----------|------|
| Jetson POST 전송 | 터미널 `POST 200 OK` |
| DB 데이터 증가 | 위 watch 명령 |
| Student PWA 혼잡도 표시 | Pi 화면 또는 `http://SERVER_IP/student/index.html` |
| Admin 카운팅 패널 갱신 | `http://SERVER_IP/admin/index.html` → 녹색 dot + 수치 |

## 트러블슈팅

| 증상 | 원인 | 해결 |
|------|------|------|
| FPS < 10 | TensorRT 미적용 | `.pt` 쓰는지 확인 → `.engine`으로 전환 |
| `/dev/video0` 없음 | CSI 케이블 방향 오류 | 케이블 재삽입 (파란 면 방향 확인) |
| TensorRT 변환 실패 | CUDA 메모리 부족 | Jetson 재부팅 후 재시도 |
| POST 실패 | 서버 IP 오류 / 서버 미실행 | `ping SERVER_IP` → Flask 실행 확인 |
| 중복 카운팅 | FPS 낮아 Track ID 끊김 | TensorRT 사용 확인, conf=0.5 유지 |
| Jetson 과열 | 방수함 밀폐 | 외벽 히트싱크 접촉 확인, 팬 추가 검토 |
| Pi 화면 안 나옴 | kiosk 서비스 미실행 | `systemctl status bustago-kiosk` 확인 |
| Jetson 없음/고장 | 부품 미도착 | PC 웹캠으로 대체: `python3 counter.py --camera 0 --model yolo11n.pt --debug` |

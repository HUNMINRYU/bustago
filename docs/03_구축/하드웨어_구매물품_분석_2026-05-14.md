# 하드웨어 구매 물품 분석

- 작성일: 2026-05-14
- 대상: BUSTAGO 하드웨어 시연/구축용 구매 예정 물품
- 기준: 제공된 구매 목록 이미지, Raspberry Pi 및 NVIDIA Jetson 공식 문서
- 주의: 사진과 상품명 기준 분석이므로 실제 상세 SKU, 구성품 포함 여부, 판매자 옵션은 별도 확인이 필요하다.

## 1. 한 줄 결론

구매 방향은 프로젝트 목적에 맞지만, **Jetson 전원**과 **Raspberry Pi Camera V2를 Jetson에 연결하기 위한 15핀-to-22핀 CSI 변환 케이블**이 빠지면 핵심 카운팅 시연이 막힐 수 있다.

## 2. 구매 물품 목록과 역할

| 물품 | 수량 | 프로젝트 내 역할 | 판단 |
|---|---:|---|---|
| Raspberry Pi 7인치 정전식 터치 LCD | 1 | 정류장 키오스크, 학생용 UI, 시연 화면 표시 | 적합 |
| Raspberry Pi NoIR Camera Module V2 | 1 | 승하차 인원 촬영용 카메라 후보 | 조건부 적합 |
| Raspberry Pi 4 Model B 4GB | 1 | 터치 LCD 구동, 웹 UI 표시, 간단한 게이트웨이 | 적합 |
| microSDXC 64GB | 2 | Raspberry Pi OS, Jetson OS 저장장치 | 기본 가능 |
| Raspberry Pi Camera Cable 300mm | 1 | Raspberry Pi 4와 카메라 연결 | Pi 4에는 적합 |
| USB-C PD 100W 충전기 | 1 | Raspberry Pi 4 전원 후보 | Pi 4용으로는 가능, Jetson용으로는 부적합 가능성 큼 |
| Jetson Orin Nano Super Developer Kit | 1 | YOLO/DeepSORT 기반 인원 카운팅 추론 장치 | 핵심 장비로 적합 |

## 3. 권장 시스템 역할 분리

가장 현실적인 구성은 Raspberry Pi와 Jetson의 역할을 분리하는 것이다.

```text
[Camera] -> [Jetson Orin Nano]
              |
              | crowd count API 전송
              v
          [Backend 서버]
              ^
              |
[Raspberry Pi 4 + Touch LCD] -> 학생/시연 UI 표시
```

| 장치 | 권장 역할 |
|---|---|
| Jetson Orin Nano | 카메라 입력, YOLO 추론, 승차/하차 카운팅, backend로 카운팅 데이터 전송 |
| Raspberry Pi 4 | 터치 디스플레이 UI 표시, 정류장 키오스크, 시연용 브라우저 |
| Backend 서버 | 혼잡도 예측, 추천 API, 카운팅 데이터 저장 |
| Frontend | 학생 화면, 관리자 화면, 시연 화면 |

Raspberry Pi 4에서 YOLO 실시간 추론까지 처리하는 것은 성능상 위험하다. 프로젝트의 `hardware/counter.py` 계열 카운팅 로직은 Jetson에서 실행하는 구조가 더 타당하다.

## 4. 주요 리스크

### 4.1 Jetson 전원 리스크

사진의 USB-C PD 충전기는 Raspberry Pi 4 전원으로는 사용할 수 있을 가능성이 높지만, Jetson Orin Nano Developer Kit 전원용으로 보면 위험하다.

NVIDIA 공식 문서 기준 Jetson Orin Nano Developer Kit의 USB-C 포트는 data only로 설명되며, 전원 입력은 DC barrel jack을 사용한다. 따라서 Jetson 키트에 전원 어댑터가 포함되어 있지 않다면 별도 **19V DC 어댑터**가 필요할 가능성이 크다.

판단:

- Raspberry Pi 4 전원: USB-C PD 충전기 사용 가능성이 높음
- Jetson Orin Nano 전원: USB-C PD 충전기만으로는 부적합 가능성 큼
- 제출/시연 전 확인 필요: Jetson 키트 구성품에 19V DC 어댑터가 포함되는지

### 4.2 카메라 케이블 리스크

Raspberry Pi Camera Module V2는 Raspberry Pi 4에는 일반 CSI 케이블로 연결할 수 있다. 그러나 Jetson Orin Nano Developer Kit의 CSI 카메라 커넥터는 22핀이고, Raspberry Pi Camera V2는 일반적으로 15핀 카메라 커넥터를 사용한다.

즉, 카메라를 Jetson에 연결해 YOLO 카운팅을 수행하려면 사진의 300mm Raspberry Pi 카메라 케이블만으로는 부족할 수 있다. 별도 **15핀-to-22핀 CSI 변환 케이블**이 필요하다.

판단:

- Pi 4 + Camera V2: 현재 케이블로 가능
- Jetson + Camera V2: 15핀-to-22핀 변환 케이블 필요 가능성 큼
- 제출/시연 전 확인 필요: Jetson용 CSI 변환 케이블 구매 여부

### 4.3 NoIR 카메라 조명 리스크

NoIR 카메라는 적외선 필터가 없는 모델이다. 어두운 환경에서 IR 조명과 함께 쓰기에는 유리하지만, IR LED나 충분한 조명 없이 자동으로 야간 화질이 좋아지는 카메라는 아니다.

버스 내부, 정류장, 실내 시연 환경처럼 조명이 일정하지 않은 경우 카운팅 정확도가 흔들릴 수 있다.

확인 필요:

- 실제 설치 장소 조도
- 야간 또는 실내 어두운 환경 사용 여부
- IR LED 또는 보조 조명 필요 여부
- 카메라 설치 각도와 문 영역 시야 확보 여부

### 4.4 저장장치 리스크

64GB microSD는 Raspberry Pi OS나 Jetson OS 구동에는 기본적으로 가능하다. 다만 Jetson에서 모델 파일, 로그, 영상 샘플, 학습 데이터, Docker 이미지까지 다루면 여유가 빠르게 줄어들 수 있다.

장기 운영 또는 반복 실험을 고려하면 Jetson용 SSD를 추가하는 편이 안정적이다.

## 5. 현재 물품만으로 가능한 것

| 시나리오 | 가능 여부 | 설명 |
|---|---:|---|
| Raspberry Pi 4 + 터치 LCD UI 표시 | 가능 | 정류장 키오스크/학생 화면 시연 가능 |
| Raspberry Pi 4 + Camera V2 연결 테스트 | 가능 | Pi용 CSI 케이블이 있으면 기본 촬영 테스트 가능 |
| Jetson에서 YOLO 카운팅 실행 | 조건부 | Jetson 전원, OS, 모델, 카메라 연결 수단 필요 |
| Jetson + Raspberry Pi Camera V2 직접 연결 | 조건부 | 15핀-to-22핀 CSI 변환 케이블 필요 가능성 큼 |
| 실제 버스 문 승하차 카운팅 시연 | 조건부 | 카메라 고정, 조명, 각도, 테스트 데이터 필요 |
| 장시간 운영 | 미흡 | 전원 안정성, 냉각, 저장장치, 케이스/거치대 필요 |

## 6. 추가 구매 또는 확인이 필요한 항목

### 필수 확인

- Jetson Orin Nano Super Developer Kit에 19V DC 전원 어댑터가 포함되어 있는지
- Raspberry Pi Camera V2를 Jetson에 연결할 15핀-to-22핀 CSI 변환 케이블이 있는지
- Jetson에서 사용할 microSD 이미지와 JetPack 버전
- 카메라가 Jetson에서 IMX219 장치로 인식되는지

### 추가 구매 가능성이 높은 항목

- Jetson용 19V DC barrel 전원 어댑터
- 15핀-to-22핀 CSI 변환 케이블
- 카메라 고정 브라켓
- Raspberry Pi/Jetson 케이스 또는 마운트
- Jetson 냉각 팬 또는 방열 보강
- IR LED 또는 보조 조명
- Jetson용 SSD
- 현장 설치용 연장 케이블, 케이블 타이, 고정 부품

## 8. 시연 전 체크리스트

- [ ] Jetson 전원이 정상 인가되는지 확인한다.
- [ ] Jetson에 JetPack이 설치되고 부팅되는지 확인한다.
- [ ] Jetson에서 카메라가 인식되는지 확인한다.
- [ ] Raspberry Pi Camera V2를 Jetson에 연결할 변환 케이블을 확보한다.
- [ ] Raspberry Pi 4에서 터치 LCD가 정상 출력되는지 확인한다.
- [ ] 터치 입력이 정상 동작하는지 확인한다.
- [ ] Jetson에서 YOLO 모델이 실행되는지 확인한다.
- [ ] 카메라 영상에서 문 영역이 충분히 보이는지 확인한다.
- [ ] 카운팅 결과가 backend `/api/crowd-count`로 전송되는지 확인한다.
- [ ] frontend에서 최신 혼잡도 또는 카운팅 결과가 표시되는지 확인한다.
- [ ] 조명이 어두울 때 카운팅 정확도가 유지되는지 확인한다.
- [ ] 시연용 fallback 데이터와 실제 카메라 데이터가 구분되도록 준비한다.

## 9. 결론

사진의 물품 구성은 BUSTAGO의 하드웨어 시연 구조에 대체로 맞다. Raspberry Pi 4와 7인치 터치 LCD는 정류장 UI 또는 시연 화면에 적합하고, Jetson Orin Nano는 YOLO 기반 인원 카운팅 장치로 적합하다.

다만 현재 구성만 보고 바로 카메라 기반 Jetson 카운팅이 가능하다고 판단하면 안 된다. 제출/시연 관점에서 가장 먼저 확인해야 할 것은 다음 두 가지다.

1. Jetson 전원 어댑터가 실제로 준비되어 있는가.
2. Raspberry Pi Camera V2를 Jetson에 연결할 15핀-to-22핀 CSI 변환 케이블이 있는가.

이 두 항목이 해결되면 하드웨어 구성은 프로젝트 시연용 아키텍처와 잘 맞는다. 반대로 이 두 항목이 빠지면 터치 UI 시연은 가능해도, 핵심인 실시간 카메라 카운팅 시연은 지연될 가능성이 높다.

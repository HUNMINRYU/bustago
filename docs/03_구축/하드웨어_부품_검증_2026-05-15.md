## 1. 한 줄 결론

5/14 외부 보고서가 지적한 2대 리스크 중 **Jetson 전원은 해결**됐고, **CSI 변환 케이블은 미확정**. 단 USB 웹캠 보유분이 동작하면 케이블 리스크 자체를 우회할 수 있어 **USB 웹캠 동작 검증을 최우선**으로 진행한다.

## 2. 외부 분석 보고서 주장 검증 (NVIDIA·Pi 공식 기준)

| 외부 주장 | 검증 결과 | 출처 |
|---|---|---|
| Jetson Orin Nano Devkit의 USB-C는 **data only**, 전원은 **DC barrel jack** 사용 | ✅ 정확 | NVIDIA 공식 (Jetson Orin Nano Devkit Hardware Spec): "USB-C — For data only" 명시, 정식 전원 DC barrel jack 5.5×2.5mm |
| Jetson CSI 커넥터는 **22핀 / 0.5mm 피치**, Pi Camera V2는 15핀 → **15→22핀 변환 케이블 필요** | ✅ 정확 | NVIDIA 공식: "22-position flex connectors, 0.5mm pitch" + "라즈베리파이 카메라 연결 시 15-pin to 22-pin conversion cable 필요" 명시 |

결론: 외부 보고서의 두 핵심 주장 모두 공식 문서로 100% 검증됨.

## 3. 내부 가이드 정합성 점검

`docs/03_구축/HW_설치_가이드_Part1_Jetson.md`는 두 리스크를 **이미 알고 있음**:

- §0.1 부품 체크리스트: "전원 어댑터 (DC **9~19V, 5A 이상**)" 명시
- §0.1 부품 체크리스트: "CSI 리본 케이블 (**15핀→22핀 변환**, 60cm)" 명시
- §3.1: `Jetson CSI 포트 (CAM0) ← CSI 리본 케이블 (22핀 측) ← 변환 커넥터 ← Pi Camera (15핀 측)` 연결도

즉 외부 감리가 새로 발견한 게 아니라, **"가이드는 알고 있지만 구매 목록(사진) 단계에서 누락"** 된 정합성 갭을 지적한 것.

## 5. 다음 액션 (우선순위 순)

### Step 1 (최우선, ~10분) — USB 웹캠 동작 검증

성공 시 CSI 변환 케이블 문제 자체가 사라짐. `counter.py`가 `cv2.VideoCapture(0)`로 USB·CSI 모두 받는 구조라 코드 변경 불필요.

```bash
# Jetson 부팅 후 USB 웹캠 연결 상태:

# 1) 장치 인식
ls /dev/video*
# → /dev/video0 보이면 OK

# 2) 1프레임 캡처 테스트
python3 -c "
import cv2
cap = cv2.VideoCapture(0)
ret, frame = cap.read()
print('Camera OK:', ret, frame.shape if ret else 'FAIL')
cap.release()
"
# → 'Camera OK: True (480, 640, 3)' 같은 출력이면 성공

# 3) counter.py 디버그 모드로 YOLO + 웹캠 실시간 동작
cd ~/bustago/hardware
python3 counter.py --camera 0 --model yolo11n.pt --debug
# → 사람 박스 + FPS 표시되면 시연 가능
```

성공 시 → **USB 웹캠 단일 경로로 시연 진행** (CSI/Pi Camera V2 경로 제외, 가장 단순).

### Step 2 — CSI 케이블 정체 식별 (보유 케이블 사진 촬영)

USB 웹캠이 안 되거나, 백업으로 Pi Camera V2 경로도 살리고 싶을 때.

| 케이블 종류 | 한쪽 끝 | 반대쪽 끝 | 변환 여부 |
|---|---|---|---|
| 일반 Pi 카메라 케이블 | 15핀 / 폭 ~12mm / 1.0mm 피치 | 15핀 (동일) | ❌ |
| **15→22핀 변환 케이블** | 15핀 / 폭 ~12mm / 1.0mm 피치 | **22핀 / 폭 ~17mm / 0.5mm 피치** (핀이 더 촘촘) | ✅ |

판정: **양 끝 폭이 다르면 변환 케이블**. 라벨에 "22-pin" 또는 "Jetson" 표기 있으면 확정.

### Step 3 — 변환 케이블 추가 구매 (Step 1·2 둘 다 안 될 때)

- 검색어: "Raspberry Pi Camera V2 to Jetson Nano CSI 15 to 22 pin cable"
- 예상 가격: ~5~15k원
- 배송: 국내 1~2일

## 6. 시연·경진대회 영향 평가

| 시나리오 | 결과 | 시연 가능? |
|---|---|---|
| Step 1 (USB 웹캠) 성공 | CSI/Pi Camera V2 경로 미사용, 웹캠만으로 카운팅 | ✅ 6/04 OK |
| Step 1 실패 + 보유 케이블 = 변환 케이블 | Pi Camera V2 + Jetson 직결 | ✅ 6/04 OK |
| Step 1 실패 + 보유 케이블 = 일반 케이블 | 변환 케이블 추가 구매 필요 (~2일) | ⚠️ 5/22까지 발주 권장 |
| 셋 다 실패 | Pi 4 + Pi Camera V2로 시연 우회 | ⛔ 카운팅 성능 부족 (보고서 §3 지적) |

D-20(6/04) 관점에서 **5/22까지** 카메라 경로 1개 확정 필요. Step 1·2를 5/15~17 안에 끝내는 게 안전.

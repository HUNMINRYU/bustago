## 6. 비상 대응

### 6.1 카메라 / 디바이스 문제

| 증상 | 대응 |
|---|---|
| `/dev/video0` 없음 | `lsusb` / `v4l2-ctl --list-devices` 확인, 케이블 재연결 |
| 카메라 인식되지만 영상 검은색 | 캡 제거, 다른 USB 포트, 다른 카메라 시도 |
| ffmpeg "Device busy" | counter.py가 점유 중 — 둘 중 하나만 실행 |

### 6.2 추론 / 네트워크 문제

| 증상 | 대응 |
|---|---|
| counter.py 시작 안 됨 | `python3 -c "from ultralytics import YOLO; YOLO('yolo11n.pt')"` 사전 다운로드 |
| POST 실패 | backend 살아있는지 확인, 방화벽/포트 확인. 실패해도 counter.py는 로컬에서 카운트는 진행 |
| 발표 중 추론 정지 | watchdog_jetson.sh가 5분 주기로 재시작 시도 (watchdog 활성화되어 있어야 함) |

### 6.3 영상 녹화 문제

| 증상 | 대응 |
|---|---|
| 디스크 가득 | `--output /path/to/other/disk/file.mp4`로 다른 경로 지정 |
| 백업 실패 | rsync 출력 확인, 수동으로 `cp -v` 재시도. raw 영상은 1차 경로에 있으므로 안전 |
| 녹화 도중 카메라 분리 | ffmpeg 종료됨. 부분 mp4는 보존됨 (`.meta.json`의 `exit_reason`에 ffmpeg-exit-N 기록) |

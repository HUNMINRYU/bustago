## 5. 핵심 명령어 레퍼런스

### 5.1 Jetson (류훈민)

```bash
# JetPack 상태 확인
sudo jtop

# YOLOv11 TensorRT 변환
python3 -c "from ultralytics import YOLO; YOLO('yolo11n.pt').export(format='engine', half=True)"

# 카운팅 실행 (디버그)
python3 counter.py --camera 0 --model yolo11n.engine --server http://SERVER_IP/api/crowd-count --station-id INS01 --debug

# 카운팅 실행 (서비스)
sudo systemctl start bustago-counter.service
sudo systemctl status bustago-counter.service
journalctl -u bustago-counter.service -f
```

### 5.2 Pi 4 (이건영)

```bash
# Kiosk 서비스 등록
sudo systemctl enable bustago-kiosk.service
sudo systemctl start bustago-kiosk.service

# 화면 보호기 비활성화
sudo mkdir -p /etc/X11/xorg.conf.d
sudo tee /etc/X11/xorg.conf.d/10-blanking.conf << 'EOF'
Section "ServerFlags"
    Option "BlankTime" "0"
    Option "StandbyTime" "0"
    Option "SuspendTime" "0"
    Option "OffTime" "0"
EndSection
EOF

# watchdog cron
(crontab -l 2>/dev/null; echo '*/2 * * * * pgrep -x "chromium-browse" > /dev/null || sudo systemctl restart bustago-kiosk.service') | crontab -
```

### 5.3 서버 (이트겔)

```bash
# Docker 배포
cd bustago
docker-compose up -d

# API 헬스체크
curl http://localhost/api/health

# 카운팅 데이터 확인
curl "http://localhost/api/crowd-count?station_id=INS01"
curl "http://localhost/api/crowd-count/history?station_id=INS01&limit=10"

# DB 직접 조회
sqlite3 backend/bustago.db "SELECT COUNT(*) FROM crowd_counts;"
```

### 5.4 현장 (박건우)

```bash
# WiFi 신호 확인
nmcli dev wifi list | grep "GU-Campus"

# 전원 확인 (두 보드 모두)
ping -c 3 192.168.1.101  # Jetson
ping -c 3 192.168.1.102  # Pi 4
```
